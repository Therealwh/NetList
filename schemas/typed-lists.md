# Typed IP lists\n\nThe daily update workflow resolves domains from `state/registry.json` and writes per-service `ipv4.txt`, `ipv6.txt`, `cidrv4.txt`, and `cidrv6.txt`. CIDR files contain exact host routes (`/32` and `/128`) only; they do not imply that a CDN or shared-hosting address belongs exclusively to a service. DNS answers can change. If all DNS resolution for one service fails, the previous per-service snapshot is retained.\n
